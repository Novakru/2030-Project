# 使用帮助

1. 在侧边栏打开现有 SQLite，或填写新路径后新建数据库。
2. 首次导入 MOSAIC 的 records.jsonl 和 candidates.jsonl，随后直接访问数据库即可。
3. 填写审核人，使用“上一条／下一条”翻页，或按 ID 查找。
4. 核对缺参标识、原文、规范步骤、器材类别／子型及 XDL。未完成转换会显示原因。
5. 点击“通过 → gold”或“拒绝”，可填写意见；已审核记录显示姓名、时间及决定，也可撤销。
6. 在“导出审核结果”选择全部或当前筛选，生成带 UTC 时间戳的 JSON 和 CSV。

审核只写数据库；原始 JSON 不被修改，数据库也不会自动同步文件。通过只认可转换表示，不等同于实验可行性或设备执行认证。
