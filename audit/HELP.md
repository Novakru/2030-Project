# 使用帮助

## 开始审核

1. 在左侧填写**审核人姓名**。已有默认数据库会自动打开；需要换库时展开「数据库连接」。
2. 用「本轮范围」选择待审核记录、pos / neg 和风险类别。
3. 页面一次显示一条记录，用顶部**上一条 / 下一条**翻页。只翻页不会提交判定。

## 快速找到核对位置

- **左侧黄色步骤**是当前定位的审核位置。
- **右侧**展示父记录或原文用量、当前值和已有风险证据。先核对数值、单位、容量及标签是否一致。
- 负例的**风险原因（原标注）**说明原规则为什么标记这条记录。专家应核对原因、数值与触发条件是否成立；展开「核对规则与适用条件」可检查假设和原判定器。soft 原因是条件扰动假设，不代表已经观察到失败。
- 有多个核对点时，切换上方「核对位置」。需要上下文时展开「查看相邻步骤」或「查看完整流程」。
- 新文本批次可展开「对照实验原文（提取依据）」查看完整输入。步骤、物料和数量应由该文本支持；ORD 产率、SMILES 和结构化比较单独放在参考字段，不能当作提取依据。
- 扩展批次首屏分别显示动作表达、参数完整性和设备执行支持。新增原子操作可在核对位置选择「扩展操作」，检查定义和原文是否一致。
- 规范批次使用「规范操作」定位合同。Add／Mix／Heat 等名称统一，具体方式、能量输入和时间关系仍需核对；原始表述与旧合同在「原文表述与规范映射」中保留。器材按规范类别、子型及配置显示，空子型表示来源未明确。
- `__NOT_REPORTED__` 表示原文未报告；`__QUALITATIVE__` 保留 overnight 等定性描述；`__AMBIGUOUS__` 保留歧义或范围。此类记录可以作为已表达的正例，审核时确认标识符合原文即可。
- 「其他记录」中的「提取工具未完成」只保存尚未解决的格式、事实或动作覆盖等工具问题，不计正例。旧受限批次中的「提取待补全」不是新的分类依据。
- 原始 JSON、器材、原料、来源和历史都在「完整证据与其他资料」中。
- MOSAIC 记录显示扰动机制；「模型核对建议」带原文引用，仍需专家确认，并非已证实错误。
- 显示「父记录未导入」时，原值未知；可以到「数据管理」补充导入父记录。

## 提交与撤销

- 可选填写审核意见，点击**通过并下一条**或**拒绝并下一条**，保存后自动进入后续待审记录。
- **pos 通过**表示确认其流程记录；**neg 通过**表示确认错误流程与风险标签匹配，仍保留负例标签。通过后导出为 gold 数据审核等级。
- 证据不足或标注不匹配时可拒绝，并在意见中说明原因。需要进一步核实时，也可直接「下一条」暂时跳过，状态仍为待审核。
- 用「上一条」回看已审记录，点击**撤销审核**可恢复待审核；旧决定和撤销操作保留在审核历史里。
- 「跳转与刷新」可跳到指定序号。**刷新本轮队列**会重新应用筛选条件，已审核记录可能因此移出待审队列。

## 导入与导出

- **首次导入**：左侧「数据库连接」→「首次建库并导入」，选择数据库保存位置与 JSON / JSONL 文件。
- **补充记录**：进入「数据管理」；重复 ID 会跳过，已有审核结果会保留。
- **导出**：进入「导出」，选择全部记录或当前筛选结果，再点击「生成时间戳导出」。生成后可下载 JSON 和 CSV。
- 「当前筛选结果」按数据库中的最新状态导出；如需导出通过的记录，先将审核状态筛选为「通过」。

审核结果保存在 SQLite；原始 JSON 不会被修改。导出时才合并人工决定，也不会自动认证器材或清除原始 blocker。

帮助在新标签页打开，关闭此页即可回到原来的审核位置。
